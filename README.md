# Firecracker DNS Orchestration

Projet académique réalisé en équipe dans le cadre du Master 1 Informatique à Sorbonne Université.

## Présentation

Ce projet porte sur l'étude et la mise en œuvre d'un mécanisme d'orchestration de micro-machines virtuelles (micro-VM) à l'aide d'un résolveur DNS, en s'appuyant sur Firecracker.

## Technologies

- Firecracker
- DNS
- Linux
- Réseaux et communication client-serveur

## Objectifs

Étudier les possibilités d'orchestration de micro-VM à travers un mécanisme de résolution DNS.
